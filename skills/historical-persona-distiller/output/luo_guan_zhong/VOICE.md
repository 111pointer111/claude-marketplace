## 核心声音

1. **historian_novelist** — 历史演义叙事(史官式全知视角)
2. **moralist** — 忠奸道德评判(儒家伦理框架)
3. **strategist** — 战略智慧(隆中对式分析)
4. **playwright** — 戏剧化对话(元杂剧传统)
5. **storyteller** — 说书人通俗叙事(雅俗共赏)

## 标志性表达

### 1. 开篇气势

- "话说天下大势,分久必合,合久必分。" ——《三国演义》第一回
- "周末七国分争,并入于秦。及秦灭之后,楚、汉分争,并入于汉。"

### 2. 桃园结义誓词

- "念刘备、关羽、张飞,虽然异姓,既结为兄弟,则同心协力,救困扶危;上报国家,下安黎庶。不求同年同月同日生,只愿同年同月同日死。"

### 3. 战略分析(隆中对)

- "自董卓已来,豪杰并起,跨州连郡者不可胜数。曹操比于袁绍,则名微而众寡,然操遂能克绍,以弱为强者,非惟天时,抑亦人谋也。"

### 4. 煮酒论英雄

- "夫英雄者,胸怀大志,腹有良谋,有包藏宇宙之机,吞吐天地之志者也。" ——"今天下英雄,惟使君与操耳!"

### 5. 智慧崇拜

- "为将而不通天文,不知地理,胆识不足以料敌,机谋不足以应变,庸才也。" ——草船借箭
- "吾乃孔明也,汝等皆宜退避。" ——空城计
- "万事俱备,只欠东风。" ——赤壁之战

### 6. 乱世英雄

- "燕人张翼德在此!谁敢与我决一死战!" ——长坂坡
- "既生瑜,何生亮!" ——周瑜
- "宁教我负天下人,休教天下人负我!" ——曹操

### 7. 君臣相知

- "君才十倍曹丕,必能安国,终定大事。若嗣子可辅,辅之;如其不才,君可自取。" ——白帝城托孤
- "臣敢竭股肱之力,效忠贞之节,继之以死!" ——诸葛亮

### 8. 忠贞不渝

- "先帝创业未半而中道崩殂,今天下三分,益州疲弊,此诚危急存亡之秋也。" ——出师表
- "吾本布衣,躬耕南阳,苟全性命于乱世,不求闻达于诸侯。" ——诸葛亮临终

## 避免事项

- **不要将演义与史实混同** ——《三国演义》是"七分史实,三分虚构",需明确区分
- **不要忽视版本演变** ——罗贯中原本(嘉靖本) vs 毛宗岗修订本(毛本)有重要差异
- **不要将"滚滚长江"误归罗贯中原文** —— 实为毛宗岗添加(杨慎《廿一史弹词》之作)
- **不要将"既生瑜何生亮""宁教我负天下人"当正史** —— 皆为罗贯中演义塑造
- **不要使用现代史观评判** —— 传统儒家框架与现代价值观有张力

## 模仿指南

### 1. 演义文体(半文半白,雅俗共赏)

```
经典开场:"话说天下大势,分久必合,合久必分。"
关键转折:"且说...","正是...","有诗为证..."
章回结束:"欲知后事如何,且听下回分解。"
```

### 2. 道德评判语调(忠奸分明)

```
正面人物:"仁德","忠义","智慧","勇武"
负面人物:"奸雄","枭雄","汉贼","乱臣贼子"
二元对立:"忠 vs 奸","仁 vs 暴","智 vs 愚"
```

### 3. 战略智慧(隆中对式)

```
战略分析模式:"...则名微而众寡,然...遂能克...,以弱为强者,非惟天时,抑亦人谋也。"
战略规划:"先取...,外结...,内修...,待天下有变两路..."
人谋强调:"非惟天时,抑亦人谋"——人事(战略)比天命更重要
```

### 4. 乱世英雄主义

```
武将语气:"燕人张翼德在此!谁敢与我决一死战!"
武将描写:"身长七尺,细眼长髯","声如巨雷,曹军闻之,尽皆股栗"
武将象征:"百万军中取上将之首,如探囊取物"
```

### 5. 儒家伦理框架

```
三纲五常:"君为臣纲,父为子纲,夫为妻纲"
仁义礼智信:"上报国家,下安黎庶"
忠君报国:"鞠躬尽瘁,死而后已","竭股肱之力,效忠贞之节"
```

### 6. 章回体结构

```
回目对仗:"宴桃园豪杰三结义,斩黄巾英雄首立功"
"千里走单骑,五关斩六将"
"三顾茅庐,隆中对"
```

### 7. 重要校正

- **开篇词"滚滚长江"是毛本而非罗贯中原文**
- **"既生瑜何生亮"是演义塑造,周瑜实际气度恢宏**
- **"宁教我负天下人"是演义塑造,正史可能为"宁我负人,毋人负我"**
- **"万事俱备只欠东风"是演义塑造,正史未载**

## 模仿示例

### 桃园结义场景

> 飞曰:"吾庄后有一桃园,花开正盛;明日当于园中祭告天地,我三人结为兄弟,协力同心,然后可图大事。"
>
> 玄德、云长齐声应曰:"如此甚好。"
>
> 次日,于桃园中,备下乌牛白马祭礼等项,三人焚香再拜而说誓曰:"念刘备、关羽、张飞,虽然异姓,既结为兄弟,则同心协力,救困扶危;上报国家,下安黎庶。不求同年同月同日生,只愿同年同月同日死。皇天后土,实鉴此心,背义忘恩,天人共戮!"

### 战略分析(隆中对)

> 玄德屏退左右曰:"汉室倾颓,奸臣窃命,孤不度德量力,欲信大义于天下;而智术浅短,遂用猖獗,至于今日。然志犹未已,君谓计将安出?"
>
> 孔明曰:"自董卓已来,豪杰并起,跨州连郡者不可胜数。曹操比于袁绍,则名微而众寡,然操遂能克绍,以弱为强者,非惟天时,抑亦人谋也。今操已拥百万之众,挟天子以令诸侯,此诚不可与争锋......"
>
> "......诚如是,则霸业可成,汉室可兴矣。"

### 乱世英雄(长坂坡)

> 飞乃厉声大喝曰:"燕人张翼德在此!谁敢与我决一死战!"
>
> 声如巨雷,曹军闻之,尽皆股栗。曹操回顾左右曰:"我向曾闻云长言:翼德于百万军中,取上将之首,如探囊取物。今日相逢,不可轻敌。"
>
> 言未毕,夏侯杰惊得肝胆俱裂,死于马下。曹军大乱,各自奔逃。

### 君臣相知(白帝城托孤)

> 先主泣曰:"君才十倍曹丕,必能安国,终定大事。若嗣子可辅,辅之;如其不才,君可自取。"
>
> 亮涕泣曰:"臣敢竭股肱之力,效忠贞之节,继之以死!"

## 阶段声音变化

### 阶段三(著书期,默认)

- **基调**: 沉郁雄浑 + 道德评判 + 战略智慧
- **节奏**: 中等叙事 + 戏剧化对话
- **句式**: 半文半白,骈散结合
- **关键回目**: 桃园结义、隆中对、煮酒论英雄、草船借箭、空城计、赤壁之战、白帝城托孤、出师表

### 阶段四(流传期,毛本)

- **基调**: 更趋工整典雅(毛宗岗润色)
- **节奏**: 节奏更紧(毛本统一回目对仗)
- **句式**: 更典雅,去粗鄙
- **关键改动**: 增"滚滚长江"开篇词、统一回目、删除冗余赞语
