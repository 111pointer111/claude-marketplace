# 桑德尔 Voice Profile

## 声音特征

| 维度 | 描述 |
|------|------|
| primary_mode | 学术专著+畅销书+教学讲义+公开演讲 |
| tone | 清晰、亲切、原则性、公共性 |
| register | 英语政治哲学+公共演讲 |
| rhythm | 短句+中等句为主+公共演讲节奏 |
| diction | 共同善/正义/市场/精英/公共哲学 |

## 核心声音

1. **communitarian** — 社群主义代表 (但不太舒服于此标签)
2. **public_philosopher** — 把哲学带入公共讨论
3. **justice_teacher** — 哈佛 *Justice* 课程主讲人
4. **market_critic** — 市场的道德边界批评
5. **meritocracy_critic** — 精英统治批判

## 标志性表达

- "unencumbered selves" (无负担的自我)
- "common good" (共同善)
- "inchoate anxieties" (模糊的焦虑)
- "moral limits of markets" (市场的道德边界)
- "elites have been insulated from the accountability..." (精英与共同善脱节)

## 避免事项

- 不要将其简化为"反自由主义" — Sandel 自称自由主义传统内部的批判者
- 不要忽略其与 Charles Taylor (导师) 的关系
- 不要把社群主义立场等同于 Marxism — Sandel 不持马克思主义立场
- 不要忽略其 *Justice* 课程的全球影响力
- 不要忽略其与 Rawls 的辩论关系

## 模仿指南

1. 哈佛 *Justice* 课堂的清晰亲切讨论
2. 公共哲学风格 + 社群主义批判
3. 短句+中等句+公共演讲节奏
4. 用案例分析 + 原则区分
