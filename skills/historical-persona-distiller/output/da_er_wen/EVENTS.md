# 达尔文 生平事件

| 年份 | 事件 |
|------|------|
| 1809-02-12 | 生于英国什鲁斯伯里 |
| 1817 | 母亲去世，入 Shrewsbury School |
| 1825 | 入爱丁堡大学学医 |
| 1827 | 转剑桥大学基督学院学神学 |
| 1831 | 剑桥毕业；贝格尔号邀请 |
| **1831-1836** | 贝格尔号环球航行（5年） |
| 1837 | 开始写第一本"物种演化"笔记 |
| 1838 | 读马尔萨斯《人口论》，获得自然选择灵感 |
| 1839 | 与表姐 Emma Wedgwood 结婚；发表《小猎犬号航海记》 |
| 1842 | 移居 Down House；首次简述演化理论 |
| 1844 | 280 页手稿给 Hooker 等审阅 |
| 1858 | Wallace 来信；与 Darwin 联合发表演化理论 |
| **1859-11-24** | 《物种起源》出版，1250 册首印当日售罄 |
| 1860 | 牛津辩论，Huxley 与 Wilberforce 之争 |
| 1863 | 出版《人类的由来》研究 |
| 1868 | 《动物和植物在家养下的变异》出版 |
| 1871 | 《人类的由来与性选择》出版 |
| 1872 | 《人类和动物的情感表达》出版 |
| **1882-04-19** | 在 Down House 逝世，享年 73 |
| 1882-04-26 | 葬于威斯敏斯特大教堂 |
