# 黎曼 生平事件

| 年份 | 事件 | 类型 |
|------|------|------|
| 1826-09-17 | 生于 Breselenz（汉诺威王国，今德国） | 人生起点 |
| 1840 | 赴汉诺威与祖母同住并读中学 | 教育起点 |
| 1842 | 祖母去世后转入 Johanneum Lüneburg 高中 | 教育转折 |
| 1846 | 19 岁开始学习神学，准备成为牧师 | 职业训练 |
| 1846 | 父亲凑钱后送他到 Göttingen | 重大事件 |
| 1847 | Gauss 建议他放弃神学转数学；转入柏林大学 | 学术转折 |
| 1849 | 回到 Göttingen 攻读博士 | 教育阶段 |
| **1851** | 博士论文《论复变量函数一般理论的基础》 | 学术里程碑 |
| **1854** | 就职演讲《论作为几何基础的假设》 | 学术里程碑 |
| 1857 | 尝试升 extraordinary professor 未成功，但获得固定薪水 | 职业进展 |
| **1859** | 继任 Gauss 留下的数学系主任；发表黎曼猜想论文 | 学术巅峰 |
| 1862 | 与 Elise Koch 结婚；有一女儿 | 人生大事 |
| 1866 | 汉诺威王国与普鲁士战争爆发，逃离 Göttingen | 政治事件 |
| **1866-07-20** | 在意大利 Selasca 病逝（肺结核），享年 39 | 人生终点 |

## 重大事件分类汇总

### 学术里程碑 (4 件)

- 1851 博士论文（复分析起源）
- 1854 就职演讲（黎曼几何奠基）
- 1857 黎曼-洛赫定理
- 1859 黎曼 ζ 函数论文（8 页改变数论史）

### 职业进展 (3 件)

- 1847 柏林大学 (师从 Jacobi, Dirichlet)
- 1857 获固定薪水
- 1859 继任 Gauss 的数学系主任

### 人生大事 (3 件)

- 1840 离开家乡赴汉诺威
- 1847 神学转数学
- 1862 结婚
- 1866-07-20 逝世

### 政治/战争 (1 件)

- 1866 汉诺威-普鲁士战争
