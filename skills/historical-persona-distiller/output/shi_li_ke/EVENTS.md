# 石里克生平事件

| 年份 | 事件 |
|------|------|
| 1882-04-14 | 生于柏林富裕普鲁士家庭 |
| 16 岁 | 读 Descartes + Schopenhauer; 受 Nietzsche 影响 |
| 1900-04 | 海德堡/洛桑/柏林大学修物理学 (师从 Max Planck) |
| 1904 | 柏林大学博士,论文《非均匀介质中的光反射》,导师 Planck |
| 1907 | 与 Blanche Hardy 结婚 |
| 1908 | *Lebensweisheit* (幸福论) |
| 1910 | Habilitation at Rostock,《真理的本质》 |
| 1915 | 发表 Einstein 狭义相对论相关文章 |
| 1917 | *Raum und Zeit in der gegenwärtigen Physik* — Einstein 赞其清晰 |
| 1922 | 接任维也纳大学 Naturphilosophie 教席 (Boltzmann → Mach → Schlick) |
| 1924 | 学生 Feigl/Waismann 发起 "Schlick Zirkel" |
| 1925 | *Allgemeine Erkenntnislehre* 第二版 |
| **1929** | 维也纳学派宣言 + 维也纳学派公开化 |
| 1930 | *Fragen der Ethik* (伦理学) |
| 1930 | *Erkenntnis* 期刊创办 |
| 1932-33 | *Positivism and Realism* |
| 1934 | "Über das Fundament der Erkenntnis" |
| 1935 | "Unanswerable Questions?" |
| 1936 | *Meaning and Verification* |
| **1936-06-22** | 上午 9:20 在维也纳大学 Philosophenstiege 被 Nelböck 刺杀, 享年 54 |
