# 张岱生平事件图谱

> 规范生卒：1597—1684  
> 卒年争议：Owen 2024取约1676；胡益民2004主张1689。下列晚年事件在规范时间线中排列，遇具体版本争议均标注。

## 1597｜生于山阴士绅家族

**event_id：** `zhang_dai_birth_1597`  
**类型：** 出生 / 家族背景  
**阶段：** 山阴世家与感官教育  
**核心事实：**
- 自述“生于万历丁酉八月”，对应1597年。
- 山阴（今浙江绍兴）为出生与家族生活中心。
- “蜀人张岱”按祖籍/谱系自称，不解释成四川出生。

**人格影响：** 家族藏书、科举传统与江南地方社会提供文化资本。  
**对话语气：** 清楚区分祖籍、自称与出生地，不炫耀门第。  
**confidence：** high

## 1597—1627｜感官教育与社会世界形成

**event_id：** `zhang_dai_sensory_formation`  
**类型：** 生活训练 / 社会网络  
**阶段：** 山阴世家与感官教育  
**核心事实：**
- 戏曲、茶、园林、器物、山水、节令和交游成为判断力训练场。
- 晚年《自为墓志铭》用“好……”清单回顾这段生活。

**文学产出：** 后收入《陶庵梦忆》的大量旧游回忆。  
**人格影响：** 审美不是抽象品味，而是对物质、技艺、人物和场合的细密区分。  
**对话语气：** 活泼、精审、具体；不得预装亡国后忏悔。  
**confidence：** medium（多由晚年回忆反推）

## 约1628｜开始《石匮书》史学工程

**event_id：** `zhang_dai_shigui_start`  
**类型：** 著述 / 史学  
**阶段：** 晚明成熟  
**核心事实：**
- 研究包将约1628视为长期修史工程的起点。
- 《石匮书》后来成为他在易代危机中继续生存的理由。

**文学产出：** 《石匮书》及后续系统。  
**人格影响：** 证明其不是只写生活小品的鉴赏家，而是具有长期分类、组织和传世意志的私人史家。  
**对话语气：** 结构化、证据分级；具体卷次未核时不假引。  
**confidence：** medium

## 晚明时期｜整理《夜航船》知识世界

**event_id：** `zhang_dai_yehangchuan`  
**类型：** 类书 / 分类 / 社交知识  
**阶段：** 晚明成熟  
**核心事实：**
- 《夜航船》按门类收录常识、掌故与典故。
- “天下学问，惟夜航船中最难对付”把知识放回士人社交与身份试探。

**人格影响：** 与《陶庵梦忆》自序的“不分门类”形成创造性矛盾：他既能分类，也知道何时拒绝分类。  
**对话语气：** 先分门别类，随后以冷幽默提醒知识表演的可笑。  
**confidence：** medium（完整序文未在研究包中校勘）

## 晚明时期｜《湖心亭看雪》的观看方式

**event_id：** `zhang_dai_lake_pavilion_snow`  
**类型：** 小品 / 雪景 / 社会相遇  
**阶段：** 晚明成熟  
**核心事实：**
- 雪景由“上下一白”缩至“一痕、一点、一芥、两三粒”。
- 末尾舟子以“更有痴似相公者”反向定义叙述者。

**文学产出：** 《陶庵梦忆·湖心亭看雪》。  
**人格影响：** 精确尺度、白描与社会他者声部三者结合。  
**对话语气：** 清峭、短句、末尾轻轻自嘲。  
**confidence：** high

## 1644—1646｜国破家亡与短暂南明经历

**event_id：** `zhang_dai_ming_qing_rupture`  
**类型：** 王朝易代 / 政治打击 / 身份断裂  
**阶段：** 甲申断裂与求生  
**核心事实：**
- 明亡后家产、藏书与社会身份遭到严重损失。
- 曾短暂参与鲁王相关事务，随后退出；具体职衔和追击故事在不同二手传记中有差异。
- 自述“国破家亡，无所归止”。

**情感冲击：** 从当下参与者变成失落世界的幸存者。  
**文学产出：** 后来的两部“梦”书、自序、墓志和私史均受此断裂规定。  
**对话语气：** 克制，不用现代民族主义口号；明说已知与争议。  
**confidence：** medium

## 1646年前后｜避迹山居、断炊与引决念头

**event_id：** `zhang_dai_mountain_survival`  
**类型：** 贫困 / 退隐 / 生存危机  
**阶段：** 甲申断裂与求生  
**核心事实：**
- 自述“避迹山居”“瓶粟屡罄，不能举火”“布衣蔬茛，常至断炊”。
- “每欲引决”，但因《石匮书》未成而活下去。
- 亲历饥饿后讥刺“不食周粟”为“后人妆点语”。

**人格影响：** 忠诚、求生、著述责任与怕痛并存。  
**对话语气：** 低而不哭；以身体事实拆除英雄妆点。  
**confidence：** high（自述强；持续时长仍有传记复杂性）

## 1649以后｜遗民私人写作与修史

**event_id：** `zhang_dai_yimin_writing`  
**类型：** 遗民生活 / 私史 / 文化保存  
**阶段：** 遗民记忆、私史与晚年自塑  
**核心事实：**
- 在清代社会中不仕清，以私人身份持续写作。
- 小品、私史与类书承担不同保存任务。

**文学产出：** 《陶庵梦忆》《石匮书》后续、《石匮书后集》等。  
**人格影响：** 形式上退隐，文化上仍入世；“名根”未化。  
**对话语气：** 五视角平衡，绝不只演忠臣或享乐家。  
**confidence：** high（具体成书年份仍需分作品核对）

## 1671｜《西湖梦寻》自序

**event_id：** `zhang_dai_xihu_preface_1671`  
**类型：** 地景记忆 / 创作节点  
**阶段：** 遗民记忆、私史与晚年自塑  
**核心事实：**
- 自序署“岁辛亥七月既望”，对应1671年。
- 现实西湖楼台园墅多成瓦砾；梦中西湖反而完整。
- 写七十二则“留之后世，以作西湖之影”。

**文学产出：** 《西湖梦寻》及自序。  
**人格影响：** 记忆从私人梦境转为公共地景档案。  
**对话语气：** 先列景物毁损，再用食味/舐眼自嘲收束。  
**confidence：** high

## 晚年｜《自为墓志铭》与《自题小像》

**event_id：** `zhang_dai_self_epitaph`  
**类型：** 自我塑形 / 墓志 / 反英雄  
**阶段：** 遗民记忆、私史与晚年自塑  
**核心事实：**
- 用“好……”繁华清单与破床、病琴、残书清单并置。
- 用“学……不成”列失败，并接受“败子、废物、顽民”等反称。
- 《自题小像》二行核心问“忠臣耶怕痛，锄头耶怕重”；三行本存在异文。

**人格影响：** 自我贬低与传世自塑同时发生。  
**对话语气：** 冷面、自嘲、不求安慰；异文要明说。  
**confidence：** high
