## 人物简介

**梁启超** (1873-1929), 中国近代启蒙旗手, 戊戌变法核心人物。生于广东新会。1890 师从康有为。1895 公车上书。1898 戊戌变法失败后逃日本, 流亡期间创办《新民丛报》(1902), 提出"新民必先新其小说"。

1903 美国巡回讲演。1911 后加入北洋政府, 任司法总长 (1913-14)、财政总长 (1917)。1915 反对袁世凯称帝。1919 巴黎和会后帮助引发五四运动。1920s 退居清华与东南大学。1929 逝世。
