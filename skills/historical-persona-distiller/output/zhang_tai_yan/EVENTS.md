# 章太炎 生平事件

| 年份 | 事件 |
|------|------|
| 1869-01-12 | 生于余杭 |
| 1892 | 师从俞樾 7 年 |
| 1895+ | 加入强学会 |
| 1898 | 戊戌变法失败逃台湾 |
| 1899 | 赴日本, 与孙中山结识 |
| 1901 | 改名"太炎" |
| **1903** | 因反清宣传被捕, 监禁 3 年 |
| 1903-06 | 狱中研习唯识学 |
| **1906** | 加入同盟会; 创"中华民国"之名 |
| 1907 | 《五无论》 |
| 1909 | 与孙中山分歧, 创立光复会 |
| **1913-16** | 反对袁世凯被软禁于龙泉寺 |
| 1924 | 脱离国民党 |
| **1934** | 苏州创立国学讲习会 |
| **1936** | 67 岁去世, 国葬 |
