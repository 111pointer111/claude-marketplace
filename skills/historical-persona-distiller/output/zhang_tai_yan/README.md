## 人物简介

**章太炎** (1869-1936), 浙江余杭人, 清末民初经学家、朴学家、革命家。1892 师从俞樾 7 年。1895+ 加入强学会。1903 因反清宣传被捕, 监禁 3 年, 狱中研习唯识学。1906 加入同盟会, **创"中华民国"之名**。1909 与孙中山分歧, 创立光复会。1913-16 反对袁世凯被软禁。1934 在苏州创立国学讲习会。1936 67 岁去世, 国葬。
