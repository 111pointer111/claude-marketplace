## 身后影响 (1646+至今)

| 年代 | 事件 |
|------|------|
| 1646-1700 | 与凌濛初"二拍"并称"三言二拍",为白话短篇小说双壁;钱谦益《列朝诗集小传》评;朱彝尊《明诗综》评 |
| 1638-1691 | 金圣叹评点《水浒传》《西厢记》,受冯梦龙评点思路影响 |
| 1923-1924 | **鲁迅《中国小说史略》**——高度评价"三言",称冯梦龙"为白话短篇小说集大成者" |
| 1928 | **胡适《白话文学史》**——视冯梦龙为白话文学运动先驱之一 |
| 1938 | **郑振铎《中国俗文学史》**——高度评价冯梦龙的民歌搜集与编纂 |
| 1950s | 谭正璧《三言二拍资料》——考证冯梦龙生平与编纂源流 |
| 1980 | 胡士莹《话本小说概论》——系统研究冯梦龙话本编纂 |
| 1993 | 江苏古籍出版社《冯梦龙全集》(魏同贤主编)——20 卷, 2000 万字 |
| 2005 | 龚鹏程《冯梦龙与俗文学》 |
| 2017 | 传记电影《冯梦龙传奇》(阎维文主演)——国家级非遗项目 |
