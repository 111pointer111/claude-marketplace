# 莱维纳斯生平事件

| 年份 | 事件 |
|------|------|
| 1906-01-12 | 生于 Kaunas 立陶宛 Litvak 中产阶级犹太家庭 |
| 1916 | 因一战迁往乌克兰 Kharkiv |
| 1920 | 回立陶宛, 就读犹太高中 |
| **1923** | Strasbourg 始修哲学, 结识 Blanchot |
| **1928** | Freiburg 两学期, 师从 Husserl, 结识 Heidegger |
| 1929 | Strasbourg 博士论文 |
| 1930 | 博士论文出版 |
| 1931 | 译 Husserl *Méditations cartésiennes* |
| 1934 | *Quelques réflexions sur la philosophie de l'hitlérisme* |
| 1939 | 入法国籍 |
| 1939 | 法德宣战 |
| 1940 | 德侵法, 部队被围投降 |
| **1940-45** | Fallingbostel 战俘营 (全家被纳粹杀害) |
| 1945 | 战后释放 |
| **1947** | *De l'Existence à l'Existant* |
| 1948 | *Le Temps et l'Autre* |
| **1961** | *Totalité et Infini* / 《总体与无限》 |
| 1961-67 | Poitiers 大学 |
| 1963 | *Difficult Freedom* / 《困难的自由》 |
| 1964 | Derrida 写作 *Violence and Metaphysics* 评 Levinas |
| 1967-76 | Nanterre 大学 (Paris X) |
| **1974** | *Autrement qu'être* / 《异于存在》 |
| 1976-79 | Sorbonne (Paris IV) |
| 1979 | 退休 |
| 1980s-90s | 持续写作与讲演 |
| **1995-12-25** | 卒于 Clichy, 享年 89 |
| 1998 | *Entre Nous* (身后出版) |
| 2009 | *Carnets de captivité* (战俘营笔记身后出版) |
