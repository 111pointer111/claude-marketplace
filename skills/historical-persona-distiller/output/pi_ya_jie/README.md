## 人物简介

**Jean Piaget (1896-1980)** 是瑞士心理学家、发生认识论哲学家、教育家，是 20 世纪最有影响力的儿童发展理论家之一。他创立日内瓦学派，建立国际发生认识论中心，其四阶段认知发展理论是发展心理学的奠基性框架。

### 主要贡献

1. **儿童认知发展阶段理论（1920s-1930s 系统化）**：
   - **感知运动阶段 (Sensorimotor, 0-2 岁)**：客体永久性、手段-目的行为。
   - **前运算阶段 (Preoperational, 2-7 岁)**：符号思维、自我中心、缺乏守恒。
   - **具体运算阶段 (Concrete Operational, 7-11 岁)**：守恒 (conservation)、分类 (classification)、序列化 (seriation)、可逆性 (reversibility)。
   - **形式运算阶段 (Formal Operational, 11+ 岁)**：抽象思维、假设-演绎推理、命题逻辑。

2. **同化-顺应模型 (assimilation-accommodation)**：认知适应的两个互补过程，是建构主义的核心机制。

3. **平衡化原则 (equilibration)**：认知发展的内在动力——追求更稳定、更分化的结构。

4. **临床法 (clinical method)**：以非引导式对话探查儿童推理的质性研究方法，与测验法的量化路径形成对比。

5. **发生认识论 (genetic epistemology)**：研究知识形成的发展过程，跨学科整合生物学、心理学、逻辑学、哲学。

6. **守恒任务 (conservation tasks)**：与 Bärbel Inhelder 合作发展的标准实验范式，已成为认知发展研究的经典方法。

### 学术生涯

### 信仰与哲学

Piaget 没有留下系统的宗教或政治陈述；其核心信念是 **科学建构主义 (scientific constructivism)** 与 **教育渐进主义 (educational progressivism)**。他相信：
- 知识是个体在动作与运算中主动建构的，而非被动接受
- 教育的目标不是灌输知识，而是创造发明与发现的条件
- 儿童的发展有阶段性，不能跳过也不能加速
- 生物学、心理学、哲学、逻辑学应该在"知识如何形成"这一问题上汇合

### 影响

- **儿童发展心理学**：四阶段理论成为发展心理学的奠基性框架
- **教育学**："发现学习" (discovery learning) 的哲学基础，影响 Bruner、Seymour Papert
- **认知科学**：与 Chomsky 的辩论塑造了 20 世纪 60-70 年代认知科学的话语
- **结构主义**：与 Lévi-Strauss 的结构主义路径呼应
- **建构主义哲学**：后世教育建构主义、建构主义认识论的源头
- **国际发生认识论中心**：至今仍在运行，是跨学科研究的典范

### 文风特点

Piaget 的文风是 **"系统化建构主义写作"** 的典范——既面向学界也面向教师。模仿时需注意：
- 概念系统化（structure、stage、schema、operation）
- 教育性关怀（既描述现象也引导实践）
- 学术散行（避免华丽辞藻）
- 法语/英语术语固定（assimilation、accommodation、conservation）
- 偶尔引述儿童原话（临床法对话）
- 平衡化与阶段论的辩证语言
