# 特斯拉 生平事件

| 年份 | 事件 | 类型 |
|------|------|------|
| 1856-07-10 | 生于克罗地亚 Smiljan（当时奥地利帝国） | 人生起点 |
| 1875 | 入 Graz 理工大学 | 教育起点 |
| 1880 | 移居布拉格 | 职业转折 |
| 1881-1882 | 在布达佩斯电报局工作；首次构想交流电感应电动机 | 学术起点 |
| 1882 | 在巴黎爱迪生公司欧洲分公司工作 | 职业起点 |
| **1884** | 移居美国，加入爱迪生公司 | 重大转折 |
| 1885 | 离开爱迪生公司 | 职业转折 |
| 1886 | 建立 Tesla Electric Light & Manufacturing | 创业 |
| **1888** | 发表多相交流电系统演讲；与 Westinghouse 签订授权协议 | 学术里程碑 |
| 1891 | 发明特斯拉线圈 | 学术里程碑 |
| 1893 | 芝加哥世界博览会演示 AC 系统 | 国际承认 |
| 1895 | 尼亚加拉瀑布发电厂使用 AC 系统 | 工程应用 |
| **1895-03-13** | 实验室大火，丢失大量研究成果 | 重大事件 |
| 1899 | 在 Colorado Springs 进行大规模实验 | 研究巅峰 |
| 1900 | 开始 Wardenclyffe Tower 项目 | 工程转折 |
| 1905 | Wardenclyffe 项目因资金短缺停工 | 重大转折 |
| 1917 | 获得 IEEE Edison Medal | 国际承认 |
| **1943-01-07** | 在纽约 Hotel New Yorker 孤独逝世 | 人生终点 |
| 1960 | 通用大会以 'tesla' 命名磁通密度单位 | 永久纪念 |
