## 人物简介

**谭嗣同** (1865-1898), 清末维新派, 戊戌六君子之首。生于北京, 湖南浏阳人。父亲谭继洵任湖北巡抚。1884-1890s 游历 12 省, 作 200+ 首诗。1895 甲午战败后转向彻底改革。1896-1897 完成《仁学》。1898 在湖南创立南学会, 发行《湘报》。1898 任军机章京, 戊戌变法最高级别官员之一。1898-09-21 慈禧政变, 拒绝逃亡, 1898-09-28 戊戌六君子被处决于菜市口。

临终遗言: "有心杀贼, 无力回天。死得其所, 快哉快哉!" 临终诗: "我自横刀向天笑, 去留肝胆两昆仑"。33 岁早逝, 其死激励中国知识分子走向革命推翻清王朝。
