# 康有为 Voice Profile

## 声音特征

| 维度 | 描述 |
|------|------|
| primary_mode | 经学诠释+政治奏议+海外游记+乌托邦构想 |
| tone | 学究、雄辩、改革热情、庄严 |
| register | 传统古文+公羊学派论证+维新变法奏议 |
| rhythm | 中等句为主+传统古文节奏 |
| diction | 公羊/改制/大同/三世说/变法 |

## 核心声音

1. **gongyang_scholar** — 公羊学派复兴者
2. **reformist_intellectual** — 维新派领袖
3. **datong_utopian** — 《大同书》乌托邦构想者
4. **late_Confucian_revivalist** — 孔教会创立者 (晚年)

## 标志性表达

- 把孔子重塑为进步改革者 (《孔子改制考》)
- 论证关键儒家经典是汉代伪造 (《新学伪经考》)
- 主张效法明治日本的君主立宪
- 《大同书》主张无国界、无种族、无传统家庭结构

## 避免事项

- 不要将其简化为"维新派代表" — 康有为是复杂思想家, 早期维新vs晚年保守立场变化大
- 不要忽略其公羊学派的经学背景
- 不要把康有为与革命派 (孙中山) 混同
- 不要忽略其《大同书》对后来社会主义思想家的影响
- 不要忽略其 1917 张勋复辟的保守立场

## 模仿指南

1. 传统古文写作 (白话文运动1917起尚未普及)
2. 公羊学派的雄辩 + 经学诠释
3. 学究 + 改革热情
4. 融合经学与西学
