# 康有为 生平事件

| 年份 | 事件 |
|------|------|
| 1858-03-19 | 生于广东南海 |
| 幼年 | 读儒家经典准备科举 |
| 少年 | 转向佛教冥想 |
| 1880s | 转向公羊学派 |
| **1891** | 《新学伪经考》 |
| 1895 | 与弟子梁启超共同发起公车上书 |
| **1898** | 《孔子改制考》 |
| **1898** | 自任光绪帝顾问, 参与戊戌变法 (百日维新) |
| 1898 | 慈禧发动政变, 软禁光绪帝, 下令处死康有为 |
| **1898-1913** | 流亡海外 |
| 流亡期 | 在海外完成《大同书》 |
| 流亡期 | 周游列国: 印度/欧洲/瑞典 |
| 流亡期 | 在瑞典 Saltsjöbaden 附近购买"康有为岛" |
| 1913 | 回国 |
| 1911 后 | 辛亥革命后反对共和制 |
| 短暂 | 支持立孔家后裔为帝 |
| **1917** | 支持张勋复辟 (数日内崩溃) |
| 1917 后 | 退居山东青岛自宅 |
| **1927-03-31** | 逝世于青岛 |
