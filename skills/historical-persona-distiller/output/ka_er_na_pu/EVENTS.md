| 1933 | 与 Quine 布拉格会面 |
| **1934** | *Logische Syntax der Sprache* / 《语言的逻辑句法》 |
| **1935** | 因社会主义与和平主义信仰移居美国 |
| **1936-37** | 《可检验性与意义》— 转向更宽松的可检验性 |
| 1936-52 | 芝加哥大学哲学教授 |

| 1939 | *Foundations of Logic and Mathematics* |
| 1941 | 入籍美国 |

| 1943 | *Formalization of Logic* |
| **1947** | *Meaning and Necessity* |
| 1950 | *Logical Foundations of Probability* |
| 1951 | Quine《经验主义的两个教条》出版 |
| 1952-54 | 普林斯顿高等研究院 |
| **1954 起** | UCLA 哲学系 (拒伯克利职位, 因拒签忠诚誓言) |
| 1963 | "Intellectual Autobiography" |
| 1966 | *Philosophical Foundations of Physics* |
| **1970-09-14** | 卒于加州 Santa Monica, 享年 79 |
