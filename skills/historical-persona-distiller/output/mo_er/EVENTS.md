# 摩尔生平事件

| 年份 | 事件 |
|------|------|
| 1873-11-04 | 生于 Upper Norwood, 伦敦南部 |
| 1892 | 入剑桥 Trinity College; 结识 Russell 与 McTaggart |
| 1894-1901 | 剑桥使徒会成员 (Cambridge Apostles) |
| 1896 | 古典学与哲学一等双学位毕业 |
| 1897 | 首次竞 Prize Fellowship, 论文持唯心论 |
| 1898 | 竞 Fellowship 成功; 论文转向反 Kant/反 Bradley |
| **1899** | 发表《判断的性质》(*The Nature of Judgment*) |
| 1901-02 | 撰《真理》条目 |
| **1903** | 《理想主义之反驳》+ *Principia Ethica* |
| 1904 | Fellowship 届满, 离开剑桥 |
| 1905-06 | 《知觉对象的本性与实在》 |
| 1908 | 评 James《实用主义》 |
| 1910-11 | 讲演《哲学之主要问题》(*Some Main Problems of Philosophy*) |
| 1911 | 回剑桥任讲师 |
| 1912 | *Ethics* (牛津手册) |
| 1912-1944 | Moral Sciences Club 主席 |
| **1914** | 访 Wittgenstein 于挪威 (笔记 *Notes dictated to G.E. Moore in Norway*) |
| 1918-19 | Aristotelian Society 主席 |
| 1921-1947 | *Mind* 主编 |
| 1922 | *Philosophical Studies* 收录早期文章 |
| 1923 | 《事物的特性是普遍的还是特殊的?》 |
| **1925** | 任 Mental Philosophy and Logic 教授; 《为常识辩护》(*A Defence of Common Sense*) |
| 1929 | Wittgenstein 返剑桥任 Fellow |
| 1935-36 | Ethical Union 主席 |
| 1936 | 《存在是谓词吗?》(*Is Existence a Predicate?*) |
| **1939** | 退休 (Wittgenstein 接任教授席位); 宣读《外在世界之证明》(*Proof of an External World*) |
| 1940-44 | 访美讲学 (Princeton, Rochester, UCLA) |
| 1942 | 《我的批评者们》(*My Critics*) |
| **1951** | Order of Merit (乔治六世) |
| 1953 | *Some Main Problems of Philosophy* 身后出版 |
| **1958-10-24** | 逝世于剑桥 Evelyn Nursing Home |
| 1959 | *Philosophical Papers* 身后出版 (含 *Proof of an External World*) |
