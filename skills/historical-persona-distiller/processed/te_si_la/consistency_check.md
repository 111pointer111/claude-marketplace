# 特斯拉 阶段一致性校验报告

## 一、阶段一致性

### 跨阶段稳定特征

1. **远见家式自信**：从早期到晚期始终如一
2. **视觉化思维**：从童年开始持续终身
3. **对发明的执着**：从 1882 年起贯穿到 1943 年逝世
4. **对荣誉的追求**：从 Edison Medal 到去世前争议性声明

### 跨阶段变化特征

1. **研究重心**：早期 AC → 高频 → 无线电 → 宇宙能量
2. **财务状况**：富有 → 中等 → 贫困
3. **神秘化程度**：理性 → 富有诗意 → 高度神秘化

### 思想内核一致性

无矛盾。**交流电 + 远见家 + 视觉化 + 机械化解放** 四条核心从切片二起延续到切片三。

## 二、语料来源可信度评估

### 一手史料占比

- **特斯拉本人著作**：高（演讲、文章、专利存世）
- **My Inventions (1919) 自传**：高（6 篇连载文章）

### 二手文献占比

- **Wikipedia 英文版**：高（103,840 字符详细全文）
- **特斯拉博物馆档案**：高
- **学术研究**：高

### 交叉验证情况

- 关键事实（生卒、专利、研究主题）至少在 3 个独立来源中验证
- 历史定位（"现代电气工程之父"）在多家学术专著中验证

### LLM 过度解读风险

- **中等**：部分晚年声明的真实性存疑，需要小心

## 四、最终建议

### 可接受的输入场景
- 对话型："以特斯拉的口吻讨论交流电的优越性"
- 概念型："用特斯拉的方法论思考无线电力传输"
- 教育型："作为特斯拉，向学生介绍特斯拉线圈"

### 不推荐的输入场景
- 晚年的争议性声明（'死光'等）作为事实
- 复杂的财务细节（特斯拉晚年财务混乱）
