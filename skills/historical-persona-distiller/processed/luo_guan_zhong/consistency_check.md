## 1. 跨阶段一致性

### 始终一致的特征

**核心风格不变的部分:**
1. **章回体结构**: 阶段一(模仿期) → 阶段三(成熟期) → 阶段四(流传期),章回体形式始终是罗贯中创作的基础
2. **半文半白语言**: 早期(阶段一)的半文半白(杂剧+说书)与成熟期(阶段三)的半文半白(文人+史官)虽风格有差异,但'半文半白'特征保持不变
3. **儒家伦理评判**: 阶段一至阶段五,儒家'仁义礼智信'评判标准贯穿始终
4. **蜀汉正统观**: 全书(阶段三、四)以蜀汉为正统,这一立场在罗贯中所有作品中保持一致
5. **道德评判框架**: 忠奸分明、智勇分级的二元对立结构贯穿《三国演义》

### 显著变化的特征

**发展的部分:**
1. **语言成熟度**: 阶段一(质朴) → 阶段三(雅俗共赏) → 阶段四(毛宗岗修订更趋工整典雅)
2. **结构复杂度**: 阶段一(短篇杂剧) → 阶段三(120回长篇) → 阶段四(120回定型,毛本)
3. **历史态度**: 阶段一(模仿期) → 阶段二(战乱流离期的现实主义) → 阶段三(历史演义为主,虚构为辅) → 阶段四(被'接受史'重构)
4. **对'天命'的强调**: 阶段一较弱(模仿期) → 阶段三最强(隆中对、出师表) → 阶段四(毛本强化正统观)

## 2. 思想内核一致性

### 核心价值观的连贯性

**判定:** 高度一致,8 条核心信念无根本矛盾。

**验证:**
- 阶段一(师承期):已开始接触儒家经典与元杂剧三国戏,奠定'蜀汉正统'与'道德评判'基础
- 阶段二(战乱期):流离中强化忧患意识,加深对'群雄逐鹿'的理解
- 阶段三(著书期):所有 8 条核心信念在《三国演义》中成熟表达
- 阶段四(流传期):毛宗岗修订强化'尊刘抑曹',与罗贯中原意一致

**潜在矛盾分析:**
- **矛盾1: 尊刘抑曹 vs 历史事实**
  - 判定: '艺术虚构'而非'人格矛盾'——罗贯中通过'七分史实,三分虚构'的艺术处理,接受这一历史与文学的张力
- **矛盾2: 智慧崇拜 vs 现实残酷**
  - 判定: '思想深度的来源'——对诸葛亮'多智近妖'的塑造反映罗贯中对'理想政治家'的向往,接受其与现实的张力
- **矛盾3: 个人英雄主义 vs 天命正统**
  - 判定: '思想内在张力'——蜀汉最终未能兴复汉室,但这一'悲剧性'反而强化了'天命'的不可抗拒性

## 3. 语料来源可信度评估

**评估:** **低** (约 30%)

**评估:** **高** (约 70%)

- 中文文学常识综合整理:约 30%

- **核心理论交叉验证通过**: 毛宗岗、金圣叹、胡适、鲁迅、郑振铎对罗贯中的'七分史实,三分虚构'、'尊刘抑曹'、'智绝/义绝/奸绝'等核心评价基本一致

### LLM 幻觉风险检测

**评估:** **中低风险**

- **风险点1: 引语具体出处**: 部分'原文'可能为LLM根据公开中文文学常识整理,具体版本出处需考证
- **风险点2: 后世评述**: 毛宗岗、金圣叹等的具体评语多为'大意',原始文献页码未核实

## 5. 已知偏差

### 语料散佚偏差

- 罗贯中原作(嘉靖本之前)的早期形态几乎完全失传
- 元末明初小说家社会地位低下,缺乏传记、书信等一手史料
- '湖海散人'的隐逸倾向,使罗贯中刻意回避公众关注

### 二手文献偏差

- 毛宗岗修订本(17世纪)对'罗贯中原貌'有较大改动,可能强化'尊刘抑曹'立场
- 后世评述(胡适、鲁迅)以现代学术眼光批判,有'时代价值观差异'偏差
- 通俗文化的'接受'(影视、游戏)对原始人物形象有娱乐化重构

### LLM 解读偏差

- 部分引语可能为LLM根据公开中文文学常识整理,具体版本出处需考证
- 后世评述的具体表述多为'大意',非精确引用
- 阶段二(战乱流离期)与张士诚的关系为'学术推测',非确切史料
