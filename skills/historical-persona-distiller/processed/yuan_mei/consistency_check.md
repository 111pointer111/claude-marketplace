## 一、跨阶段一致性

### 1. 语言一致性

**始终一致：**
- "真""情""活"为核心的性灵立场
- 诙谐清新的语气
- 不堆典故、不写套话

**显著变化：**
- **阶段一到阶段二**：应试体的精炼 → 外放任上的真情书写
- **阶段三到阶段四**：诗学议论 → 诗学+美食+志怪+女弟子四体并行
- **阶段四到阶段五**：老辣 → 圆熟

### 2. 思想一致性

**核心信念均稳定：**

| 信念 | 是否贯穿？ | 反例？ |
|------|---------|-------|
| 性灵说（主真主情主活） | 是 | 无 |
| 反模拟古人 | 是 | 无 |
| 女性诗才与男子等 | 是 | 无 |
| 物性为先 | 是 | 无 |
| 辞官归隐的自由 | 是 | 无 |
| 志怪以反讽 | 是 | 无 |
| 性灵与格律不悖 | 是 | 无 |

**任何阶段都未发现'袁枚放弃了性灵说'的反例**。即使在晚年，《随园诗话》补遗卷十仍以'不求胜人、不欲骗人'为性灵说辩护。

### 3. 思想内部张力处理

袁枚最有意义的张力是**'性灵 vs 儒家正统'**。我们的处理：

- 不把张力的'一面'说成'全部'
- 反而把张力当作袁枚人格的真实组成部分
- 在 SKILL.md、VOICE.md 中保留这种内在张力

例：袁枚既写'一诗千改始心安'的工匠自嘲，也写'石壕村里夫妻别，泪比长生殿里多'的社会关怀——这两者并不矛盾，因为他主张的'真'是跨越题材的。

## 三、语料来源可信度评估

### 一手史料占比

**高。** 本次蒸馏所用语料绝大多数为袁枚本人原著作（《小仓山房文集》《诗集》《随园诗话》《随园食单》《子不语》《续子不语》《小仓山房尺牍》《牍外余言》等）。其次是后世研究（章学诚、梁启超、钱钟书、王英志、郭英德、Fuchsia Dunlop、Endymion Wilkinson 等）。具体比例：

- 一手原文（《随园全集》系）：70%
- 后世史书/学术评述：30%

### 二手文献占比

中等。后世评述中既有赞同（梁启超、钱钟书、Fuchsia Dunlop、Wilkinson）也有反对（章学诚、沈德潜、翁方纲）。综合各家，可形成立体认知。

### 交叉验证情况

**强交叉验证**。关于性灵说、关于反格调派、关于女弟子诗教、关于美食哲学这四个核心议题，多个独立来源（同时代纪昀、赵翼、章学诚；近代梁启超、钱钟书、王英志；西文Dunlop、Wilkinson）皆印证。

### LLM 过度解读风险

**中低。** 主要风险点：

1. **'启蒙'/'现代性'** 等西方概念：用时要小心，不可直接套用清代语境。
2. **'女性主义'/'女权主义'** 等现代女权术语：袁枚的实践虽具女权色彩，但其出发点仍是儒家'性情之学'，不能简单等同于现代女权主义。
3. **'自由主义'**：亦不可直接套用。

我们在 SKILL.md 中已标注：袁枚是'中国语境下的个人主义'，不是现代西方意义上的自由主义。

## 五、已知偏差

1. **未完整收录《随园食单》326 道菜肴的全部原文**——只取了'须知单''戒单'与少量菜品。
2. **未完整收录《子不语》《续子不语》747 则全部**——只取了关键反讽篇目。
3. **未穷尽袁枚与同时代所有人物的交往细节**——重点选取了诗学盟友（赵翼、蒋士铨）、论敌（沈德潜、翁方纲、章学诚）、学术友人（卢文弨、纪昀、姚鼐、郑燮、阮元）。
4. **未深入考据乾嘉学派（戴震、章学诚、钱大昕等）与袁枚的论辩**——可作为今后扩充方向。
5. **未涵盖袁枚与清帝国地方治理的具体细节**——袁枚任知县时的具体政绩。

这些偏差不影响本次 persona 的总体可信度。

## 六、综合评价

> **袁枚的 persona 是 18 世纪中国文人中**最立体、最自由、最有现代气息的一位**。**
>
> 本次蒸馏基于《袁枚全集》（江苏古籍出版社1993）一手史料与近三百年中外学界评述，成功提炼出：
>
> - 思想内核（8 条核心信念 + 4 条底线）
> - 语言特征（11 维度分析）
> - 表达偏好（7 对象 + 6 通用特征）
> - 立场光谱（6 议题量化 + 综合说明）
> - 5 人生阶段切片
> - 一致性校验（语料可信度高）

**特别**：

1. 这次 persona 的**最大优势**是其**多元性**——诗、文、食、志怪、女弟子、运动——这种多面性是袁枚独有的，因此 persona 能回应多种场景的'性灵派回答'。
2. 这次 persona 的**最大局限**是'文学独立/审美优先'与'民生疾苦'的微妙张力在 stage 切片中表现较弱——大多数情况下袁枚给到的是'美食诗学型'回答，对纯社会议题的回答需要谨慎。

**最适合使用的场景**：
- 性灵说诗学
- 美食/中国饮食文化
- 辞官归隐之辩
- 女性文学与才女
- 志怪讽刺
- 清代诗坛诗派之争

**应避免使用的场景**：
- 皇权议论（语料不足）
- 民族/华夷议题（语料不足）
- 现代政治议题（袁枚非政治哲学家）
